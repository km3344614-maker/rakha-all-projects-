🌐 خطوات الرفع والتشغيل على RENDER (خطوة بخطوة):
==============================================================================

الخطوة 1: رفع محتويات المجلد إلى مستودع GitHub
1. ادخل على حسابك في GitHub: https://github.com
2. اضغط على New لإنشاء مستودع جديد (Repository) باسم مثلاً: rakha-cloud-host واجعله Private.
3. ارفع جميع الملفات والمجلدات الموجودة داخل C:\Users\RAKHA\Desktop\render إلى المستودع.

الخطوة 2: إنشاء الخدمة على Render
1. ادخل على حسابك في Render: https://render.com
2. اضغط على زر 'New +' في الأعلى ثم اختر 'Web Service'.
3. اربط مستودع GitHub الذي أنشأته (rakha-cloud-host).
4. املأ الإعدادات التالية:
   • Name: rakha-cloud
   • Region: أي سيرفر تريده (مثلاً Frankfurt أو Ohio)
   • Branch: main
   • Runtime: Node
   • Build Command:
     npm install && npm run build
   • Start Command:
     node server.js
   • Instance Type: Free (أو Starter)

الخطوة 3: إضافة المتغيرات السرية (Environment Variables)
1. في صفحة الإنشاء أو داخل Settings -> Environment، اضغط 'Add Environment Variable'.
2. يمكنك نسخ محتويات ملف .env ووضعها هناك (خاصة MONGODB_URI و REVIEWS_BOT_TOKEN و JWT_SECRET).
3. اضغط 'Create Web Service' وسيبدأ Render بالبناء والتشغيل فوراً!

الخطوة 4: ربط دومينك الخاص (Custom Domain)
1. بعد اكتمال التشغيل، اذهب إلى Settings داخل الخدمة في Render.
2. انزل إلى قسم 'Custom Domains' واضغط 'Add Custom Domain'.
3. اكتب اسم الدومين الخاص بك (مثلاً: auth.yourdomain.com أو yourdomain.com).
4. انسخ سجلات CNAME أو A Record التي يطلبها Render وضعها في لوحة تحكم الدومين الخاص بك (Cloudflare / Namecheap / GoDaddy).
5. سيعطيك Render شهادة SSL (HTTPS) مجانية وتلقائية خلال دقائق!
